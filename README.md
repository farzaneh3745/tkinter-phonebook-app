# Phone Book Application (Tkinter GUI - OOP Based)

A simple desktop phonebook application built using Python and Tkinter with an object-oriented design.

## Features

- Add new contacts with first name, last name, and phone number
- Search contacts by name or phone number
- Update and delete existing contacts
- Treeview display of contact list
- Separate popup window for creating and editing contacts
- Designed with classes to separate logic from UI

## Technologies Used

- Python 3.x
- Tkinter (for GUI)
- Object-Oriented Programming (OOP)

## Project Structure

├── Entities/  
│   └── phonebook.py    # Contains the Phonebook and Contact classes  
├── main.py              # GUI application logic using Tkinter
